# 3D model provenance

The following files contain the light GLB variants of models created by Grab3D and released by the creator under [CC0 1.0](https://grab3d.com/license/), compressed losslessly with gzip. They are stylized educational representations and not microscopy scans.

- `animal.glb.gz`: [Human Cell](https://grab3d.com/models/anatomy/human-cell/)
- `plant.glb.gz`: [Plant Cell](https://grab3d.com/models/anatomy/plant-cell/)
- `bacteria.glb.gz`: [Bacteria](https://grab3d.com/models/anatomy/bacteria/)
- `neuron.glb.gz`: [Neuron](https://grab3d.com/models/anatomy/neuron/)

Run `gzip -d -k <filename>.glb.gz` to recover the original GLB file. The supplied models are each one mesh, so structure isolation is provided separately by the application's schematic models.

- `blood-cells.glb.gz`: [Blood Cells](https://grab3d.com/models/anatomy/blood-cells/) by Grab3D, CC0 1.0. Stylized representation.
