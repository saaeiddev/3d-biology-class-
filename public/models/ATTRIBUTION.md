# 3D model provenance

The following files contain the light GLB variants of models created by Grab3D and released by the creator under [CC0 1.0](https://grab3d.com/license/), compressed losslessly with gzip. They are stylized educational representations and not microscopy scans.

- `animal.glb.gz`: [Human Cell](https://grab3d.com/models/anatomy/human-cell/)
- `plant.glb.gz`: [Plant Cell](https://grab3d.com/models/anatomy/plant-cell/)
- `bacteria.glb.gz`: [Bacteria](https://grab3d.com/models/anatomy/bacteria/)
- `neuron.glb.gz`: [Neuron](https://grab3d.com/models/anatomy/neuron/)

Run `gzip -d -k <filename>.glb.gz` to recover the original GLB file. The supplied models are each one mesh, so structure isolation is provided separately by the application's schematic models.

- `blood-cells.glb.gz`: [Blood Cells](https://grab3d.com/models/anatomy/blood-cells/) by Grab3D, CC0 1.0. Stylized representation.

- `retina-cajal.glb.gz`: [Mammalian retina, NIH 3D 3DPX-018271](https://3d.nih.gov/entries/18271), 3D model by Jeremy Swan after an illustration by Santiago Ramón y Cajal, CC0 1.0 as listed on NIH 3D. Historical educational relief.
- `purkinje-cajal.glb.gz`: [Cerebellum, NIH 3D 3DPX-000786](https://3d.nih.gov/entries/786), Biovisualization LLC, courtesy of the Cajal Institute, Spanish National Research Council (CSIC), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Unmodified GLB compressed using gzip.

- `eyewire-retinal-neuron.glb.gz`: [Retinal cell 20167 from EyeWire, NIH 3D 3DPX-002682](https://3d.nih.gov/entries/2682), EyeWire, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Web-optimized output `20167_100`; compressed with gzip.

- `rod-cell.glb.gz`: [Light-Sensory Cell](https://tactiles.eu/tactiles/lichtsinneszelle/), Barbara Henn / Tactiles, [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). A tactile teaching model; the original 3MF was converted to GLB and object colors restored, then compressed with gzip.

- `microscope.glb`: [Binocular Compound Microscope](https://3d.nih.gov/entries/22786), NIH 3D 3DPX-022786, CC0 1.0. Source GLB.
